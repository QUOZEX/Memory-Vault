## 🧠 Overview
"Memory Vault" is an AI-powered Chrome extension designed to enhance productivity and browsing efficiency.  
It features:
- Smart page saving and word search  
- Automatic content capture  

---

## ⚙️ Features
- 🧩 Save and organize pages automatically  
- 💡 Search by word
- 💾 Local memory and autosave enabled  
- 🖥️ Fully offline and Windows-compatible  

---

## 🧰 Technologies Used
- HTML, CSS, JavaScript  
- TensorFlow.js (Universal Sentence Encoder)  
- Chrome Extension APIs  

---

## 🚀 Installation (Developer Mode)
1. Download or clone this repository.  
2. Open **chrome://extensions** in Chrome.  
3. Enable **Developer mode** (top right corner).  
4. Click **Load unpacked** and select the extension folder.
